# Agent Routing Policy

The primary session is the orchestrator. Use the smallest role set that can complete the task. Use `architect` for boundaries, `researcher` for current documentation, `domain` for invariants, `application` for use cases and ports, `integration` for external adapters, `platform` for cloud planning, `environment` for local/Codex Cloud tool health, and `reviewer` for independent validation. Maximum delegated depth is one and maximum concurrent child threads is four.
