# Reviewer Profiles

Profiles specialize the fixed `reviewer` Agent. They are read-only checklists, not Agent registrations, permissions, MCPs, Skills, or delegation levels.

Available profiles: `architecture`, `api-contract`, `security`, `performance`, `testing`, `release`, and `incident`.

Select the smallest relevant profile. Combine profiles only when scopes overlap. Every review reports evidence, tests actually run, findings, residual risks, and `Not Verified` states.
